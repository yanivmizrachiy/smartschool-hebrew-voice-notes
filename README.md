# חרוט — סביבת העבודה המרכזית

הריפו הזה הוא **מרכז העבודה היחיד** של פרויקט חרוט: מחקר, שליפת שאלות, בנק שאלות, סדרת דפי A4 להדפסה ו־QA.

## מקור אמת

- [`RULES.md`](RULES.md) — מקור הכללים המחייב היחיד.
- אין להסתמך על זיכרון שיחה במקום לקרוא את הריפו.

## מבנה

- [`research/`](research/) — מקורות וממצאי מחקר.
- [`research/CURRICULUM-AUDIT-5787.md`](research/CURRICULUM-AUDIT-5787.md) — ביקורת התאמה לתוכנית החדשה ז׳–ח׳ תשפ״ז.
- [`questions/`](questions/) — שאלות שנשלפו, בנק שאלות ומפת הסדרה.
- [`content/`](content/) — מקור אמת מובנה לתוכן, עמודים ומקורות.
- [`design/`](design/) — שפת העיצוב שנלמדה מ־`razpages` ו״רביע ראשון״.
- [`worksheets/`](worksheets/) — דפי תלמיד A4 להדפסה בלבד.
- [`src/`](src/) — כלי בנייה וסנכרון.
- [`tests/`](tests/) — בדיקות אוטומטיות, כולל guard להתאמת שכבת גיל וגרסת תוכנית.
- [`qa/`](qa/) — שערי איכות ובדיקות.
- [`tools/preview/`](tools/preview/) — Preview פנימי בלבד; אינו חלק מתוצר התלמיד.
- [`viewer/`](viewer/) — ממשק GitHub Pages לדפדוף ולהדפסה.
- [`print.html`](print.html) — בניית כל החוברת להדפסה מתוך מקור האמת בזמן אמת.

## זרימת עבודה

**מקור → אימות שכבת גיל/גרסת תוכנית → שליפה → סיווג → בנק שאלות → מפת דפים → דפי A4 → QA → צפייה/הדפסה**

## שלוש שכבות תוכן

- **מתוך תוכנית הלימודים** — רק שאלה רשמית שנפתחה, נשלפה וחוברה למקור רשמי מאומת **התואם גם לשכבת ז׳–ח׳ ולגרסת תשפ״ז**.
- **בהתאם לתוכנית הלימודים** — שאלה מקורית שלנו שנבנתה ישירות ממיומנות/פעילות רשמית שאומתה **במסמכי ז׳–ח׳ תשפ״ז**.
- **שאלות מקוריות שלנו** — שאלות חדשות לחלוטין, כולל חקר, תכנון, תיקון טעויות ויישום.

## מצב נוכחי

- קיימים **16 דפי A4** פעילים.
- הסדרה **פתוחה להמשך**; אין יעד מספרי קשיח.
- כל הדפים הם תרגול בלבד, לא דפי הסבר.
- יעד ההתאמה הוא **תוכנית חטיבת הביניים המעודכנת לז׳–ח׳ החל מתשפ״ז**.
- נכון לביקורת האחרונה, **16 דפי החרוט נשמרים אך אינם מאומתים כליבת תוכנית ז׳–ח׳ תשפ״ז**.
- דף 9 כולל מיומנות פיתגורס המתאימה לכיתה ח׳, אך ההקשר החרוטי עצמו עדיין אינו מאומת כליבה.
- דף 13 כולל גליל, נושא מוכר של כיתה ח׳, אך יחס חרוט–גליל עדיין אינו מאומת כליבת תשפ״ז.
- מקורות משרד החינוך של ה׳–ו׳ בנושא חרוט נשמרים כמקורות מחקר/השראה בלבד ואינם יכולים לאמת ליבת ז׳–ח׳.
- `עמוד-209.html` ב־`razpages` הוא דף החרוט המלא המרכזי שאותר עד כה ומשמש מקור ייחוס פנימי לתכנון שאלות יישומיות, לא הוכחה לתוכנית החדשה.
- שאלות רשמיות מקבלות את הכותרת **„מתוך תוכנית הלימודים”** רק לאחר שליפה ואימות בפועל של מקור התואם לשכבה ולגרסת התוכנית.
- אין דמו, placeholder, תוכן זמני או מפתח תשובות כתוצר.
- התוצר הסופי הוא A4 להדפסה בלבד; HTML/CSS משמשים כמנוע הפקה פנימי.
- GitHub Pages מציג ממשק דפדוף בין הדפים, הדפסת עמוד נוכחי והדפסת כל החוברת.

## עקרון הרחבה

מוסיפים דף חדש רק אם הוא מוסיף מיומנות, סוג שאלה או עומק חשיבה אמיתי. אין מוסיפים דפים רק כדי להגיע למספר מסוים.

אין להכריז על התאמה לתוכנית החדשה לפי קיום דף או לפי מקור יסודי. כל טענת התאמה לז׳–ח׳ חייבת לעבור `tests/curriculum-scope.mjs` ולהיות מגובה במקור הרשמי המתאים.

אין להכריז על סיום לפי קיום HTML בלבד. כל דף חייב לעבור QA מתמטי, לשוני, חזותי והדפסה לפי `qa/QUALITY-GATE.md` ו־`RULES.md`.
