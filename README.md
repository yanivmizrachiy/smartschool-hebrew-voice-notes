# חרוט — סביבת העבודה המרכזית

הריפו הזה הוא **מרכז העבודה היחיד** של פרויקט חרוט: מחקר, שליפת שאלות, בנק שאלות, 8 דפי תרגול, פתרונות ו־QA.

## מקור אמת

- [`RULES.md`](RULES.md) — מקור הכללים המחייב היחיד.
- אין להסתמך על זיכרון שיחה במקום לקרוא את הריפו.

## מבנה

- [`research/`](research/) — מקורות וממצאי מחקר.
- [`questions/`](questions/) — שאלות שנשלפו, בנק שאלות מקורי ומפת 8 הדפים.
- [`design/`](design/) — יישום שפת העיצוב של `razpages` ו״רביע ראשון״.
- [`worksheets/`](worksheets/) — דפי תלמיד בלבד; אין דפי הסבר.
- `answers/` — מפתח תשובות, ייווצר רק כשיש תוכן אמיתי.
- [`qa/`](qa/) — שערי איכות ובדיקות.

## זרימת עבודה קבועה

**מקור → שליפה → סיווג → בנק שאלות → מפת דפים → 8 דפי תרגול → פתרונות → QA → תוצר סופי**

## דרישות מרכזיות

- הרמה וסוגי השאלות נקבעים לפי דוגמאות החרוט בתוכנית הלימודים.
- כל סוג שאלה רשמי שאותר חייב להיות מיוצג בפרויקט.
- שאלה שמקורה בתוכנית הלימודים בדף תלמיד מסומנת בכותרת: **מתוך תוכנית הלימודים**.
- חומר `razpages` ממופה ונלמד; `עמוד-209.html` הוא דף החרוט המלא המרכזי שאותר עד כה.
- 8 דפי התלמיד הם **דפי תרגול בלבד**.
- העיצוב נשען על החוזים והסגנון של `razpages`, במיוחד ״רביע ראשון״.
- בכל דף מופיע הקרדיט הקבוע בן שתי השורות.
- אין דמו, placeholder, inline CSS בדפים סופיים או תוכן שנועד רק למלא שטח.

## יעד 8 הדפים

1. זיהוי ותכונות דרך תרגול.
2. פריסה ↔ חרוט.
3. טענות ותיקון שגיאות.
4. ייצוגים ומבטים.
5. השלמת פריסות והתאמות מרחביות.
6. חישובים בהתאם לרמת התוכנית הרשמית.
7. השוואות ויישומים.
8. דף מסכם בסגנון הערכה.

## מצב נוכחי

המחקר, שליפת השאלות ובנק השאלות כבר קיימים. דפי העבודה נמצאים בבנייה ולכן **אינם נחשבים סופיים** עד מעבר `qa/QUALITY-GATE.md` וכל ה־QA המוגדר ב־`RULES.md`.

אין להכריז על סיום לפי קיום HTML בלבד.
