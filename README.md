# חרוט — סביבת העבודה המרכזית

הריפו הזה הוא **מרכז העבודה היחיד** של פרויקט חרוט: מחקר, שליפת שאלות, בנק שאלות, 8 דפי תרגול ו־QA.

## מקור אמת

- [`RULES.md`](RULES.md) — מקור הכללים המחייב היחיד.
- אין להסתמך על זיכרון שיחה במקום לקרוא את הריפו.

## מבנה

- [`research/`](research/) — מקורות וממצאי מחקר.
- [`questions/`](questions/) — שאלות שנשלפו, בנק שאלות ומפת 8 הדפים.
- [`content/`](content/) — מקור אמת מובנה לתוכן, עמודים ומקורות.
- [`design/`](design/) — יישום שפת העיצוב של `razpages` ו״רביע ראשון״.
- [`worksheets/`](worksheets/) — דפי תלמיד בלבד; אין דפי הסבר.
- [`src/`](src/) — כלי בנייה וסנכרון.
- [`tests/`](tests/) — בדיקות אוטומטיות.
- [`qa/`](qa/) — שערי איכות ובדיקות.

## זרימת עבודה קבועה

**מקור → שליפה → סיווג → בנק שאלות → מפת דפים → 8 דפי תרגול → QA → תוצר סופי**

## דרישות מרכזיות

- הרמה וסוגי השאלות נקבעים לפי דוגמאות החרוט בתוכנית הלימודים.
- כל שאלה/משימה רשמית על חרוט שאותרה ונפתחה בפועל נרשמת עם מקור מדויק.
- משימה שמקורה בתוכנית הלימודים ומופיעה בדף תלמיד מסומנת בכותרת **„מתוך תוכנית הלימודים”** ומחוברת ל־`data-source` מאומת.
- אין להציג שאלה שלנו כשאלה רשמית.
- כל חומר החרוט הרלוונטי ב־`razpages` נשלף וממופה, גם כשהוא נמצא בתוך פרק כללי יותר.
- `עמוד-209.html` הוא דף החרוט המלא המרכזי שאותר עד כה ב־`razpages`.
- 8 דפי התלמיד הם **דפי תרגול בלבד**.
- העיצוב נשען על החוזים והסגנון של `razpages`, במיוחד ״רביע ראשון״.
- בכל דף מופיע הקרדיט הקבוע בן שתי השורות.
- אין דמו, demo, placeholder, lorem, תוכן זמני או תוכן שנועד רק למלא שטח.
- אין inline CSS בדפים הסופיים.

## יעד 8 הדפים

1. זיהוי ותכונות דרך משימות.
2. פריסה ↔ חרוט.
3. טענות ותיקון שגיאות.
4. ייצוגים ומבטים.
5. פריסות, חתכים וחשיבה מרחבית בהתאם למקור הרשמי.
6. חישובים בהתאם לרמת התוכנית הרשמית.
7. השוואות ויישומים.
8. דף מסכם בסגנון הערכה.

החלוקה יכולה להשתפר אם המחקר הרשמי מצדיק זאת, אבל כל שינוי נשמר במקור האמת ולא נעשה ידנית בצורה מפוזרת.

## מצב נוכחי

8 דפי HTML קיימים, אך הם **עדיין אינם סופיים**. הסיום דורש השלמת שליפת שאלות המקור, ביקורת מתמטית־לשונית, רינדור A4 בפועל, בדיקות הדפסה ותיקונים לפי `qa/QUALITY-GATE.md`.

אין להכריז על סיום לפי קיום HTML בלבד.
