# חרוט — סביבת העבודה המרכזית

הריפו הזה מיועד לכל פרויקט **חרוט**: מחקר, שליפת שאלות, בנק שאלות, ארבעת דפי העבודה המרכזיים, שאלות בסגנון תוכנית הלימודים, פתרונות ובקרת איכות.

## מקור הכללים
לפני כל עבודה חובה לקרוא את [`RULES.md`](RULES.md). זהו מקור הכללים המחייב היחיד.

## זרימת העבודה
1. **מחקר ומקורות** — `research/`
2. **שליפת שאלות וסיווג** — `questions/`
3. **סגנון ועיצוב** — `design/`
4. **דפי העבודה שנבנה** — `worksheets/`
5. **פתרונות ומפתח מורה** — `answers/`
6. **בדיקות ואיכות** — `qa/`

## כלל ארגון
- חומר מקור נשמר עם מקור ברור.
- שאלה שנשלפה אינה הופכת אוטומטית לשאלה בדף.
- שאלה מקורית שלנו חייבת לעבור את מפת השאלות ואת שער האיכות.
- אין דמו, placeholder או קבצים לצורך מילוי תיקייה.
- תיקיות תיווצרנה רק כאשר יש בהן תוכן אמיתי.

## תוצרים סופיים נדרשים
- מאגר מחקר של כל חומרי החרוט שאותרו.
- מאגר שאלות שנשלפו מ־`razpages` וממקורות רשמיים, עם תיעוד מקור.
- מקבץ **"שאלות כמו בתוכנית הלימודים"** המבוסס על המחקר.
- ארבעה דפי A4 מקוריים, מלאים ומעוצבים לפי הסטנדרט של `razpages` ו"רביע ראשון".
- מפתח תשובות מאומת.
- QA מתמטי, לשוני, חזותי והדפסה.

## מצב עבודה
המחקר והסיווג מתקדמים. אין להכריז על השלמה לפי קיום HTML בלבד; ההשלמה נקבעת רק לפי `RULES.md` ו־`qa/QUALITY-GATE.md`.
