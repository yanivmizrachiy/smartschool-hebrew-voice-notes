## שאלת משרד החינוך

שאלת גביע ה״מיני־מקס״ נשמרה, תומללה ומשובצת בדף 33 עם הכותרת **„מתוך תוכנית הלימודים”**. היא מגיעה רק אחרי דפי הכנה של חתך צירי, פיתגורס, גובה ונפח.

## הדפים החזותיים

- „כמה חרוטים מסתתרים בתמונה?” — 15 חרוטים.
- „איפה מסתתר החרוט?” — חרוט אחד.
- שני דפי התשובות משתמשים באותה סצנה: הרקע בשחור־לבן ורק החרוטים הנכונים בצבע.
- `anis-basics` — „מה המצב הלימודי של אניס?”
- `jerusalem-cone-vision` — למידת חרוט בירושלים.
- `cone-in-my-head` — „הכול חרוט לי בראש”.
- `world-of-cones` — „עולם החרוטים”.
- ארבעת דפי התמונה המלאים מופיעים ללא footer גלוי, לפי דרישת המשתמש.
- עמודי הצבע מפוזרים לאורך הספר ולא מרוכזים בסופו.

## עיקרון

הפרויקט עוסק רק בחרוט. אין דמו, אין כפילויות מכניות, וכל דף חדש חייב להוסיף מיומנות, ייצוג, חשיבה או הקשר משמעותי. החוברת צריכה להרגיש כמו ספר לימוד אחד אחיד ומדורג, לא כאוסף דפי עבודה.
