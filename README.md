# חרוט — חוברת עבודה מדורגת

הריפו הזה הוא מקור העבודה של חוברת **חרוט**: תוכן, מקורות, דפי A4, דפים חזותיים, אפליקציית דפדוף, חבילת הדפסה ו־QA.

## מצב נוכחי

- **38 דפי עבודה A4**.
- **8 דפים חזותיים A4**.
- **46 דפי A4 בחוברת המלאה**.
- הרצף: יסודות → מידות → נפח → חתך צירי → שטח חתך → פיתגורס → המרות → יישומים → שאלת משרד החינוך → העמקה והערכה.
- דף 17 נשאר source-locked.

## מקור אמת

הסדר והספירה נקבעים ב־`content/workbook.json`. ייחוס המקורות נשמר ב־`content/source-registry.json`. חוזה הפרויקט נמצא ב־`RULES.md`, וסדר הספר מתועד ב־`research/BOOK-SEQUENCE-46.md`.

אין להסתמך על זיכרון שיחה במקום מצב הריפו.

## פקודות איכות

- `npm run build` — מסנכרן את דפי ה־worksheet והדפים החזותיים ממקור האמת.
- `npm run build:print` — בונה את חבילת ההדפסה המאוחדת.
- `npm run validate` — מפעיל את כל חוזי התוכן, המתמטיקה, המספור, המקורות, הדפים החזותיים והיגיינת הריפו.
- `npm run check` — build + print + validate.
- `npm run render:pages` — מרנדר את רצף A4 דרך Chrome כאשר שרת מקומי פעיל ב־`127.0.0.1:4173`.

## CI

`Cone workbook quality` רץ על PR ל־`main` ועל `main`. `Textbook layout render` מרנדר את כל 46 העמודים ומעלה את התמונות כ־artifact לצורך בדיקה חזותית.

## מבנה הריפו

- `content/` — manifest ורישום מקורות.
- `worksheets/` — 38 דפי worksheet.
- `visual-pages/` — 8 דפי חוויה/תשובה.
- `visual-assets/` — נכסים חזותיים מקומיים.
- `questions/` — מקורות, מפת שאלות ומפתח תשובות פנימי.
- `research/` — מחקר, פדגוגיה ורצף הספר.
- `viewer/` — אפליקציית הדפדוף וההדפסה.
- `src/` — מנועי build.
- `tests/` — חוזי איכות קבועים.
- `qa/` — ביקורות ותיעוד QA.
- `print/harut-a4.html` — חבילת ההדפסה המאוחדת לאחר build.

## היגיינת ריפו

קבצי staging, קובצי `*.b64`, workflows חד־פעמיים, קובצי `DO-NOT-MERGE`, סקריפטי `tools/apply-*` ופלט `qa/layout-pages/` אינם חלק ממקור האמת. `tests/repo-hygiene.mjs` מונע מהם לחזור ומוודא שאין תלות של תוצר התלמיד בקישורי Google Drive פרטיים.

## פער חזותי ידוע

`qa/VISUAL_SOURCE_AUDIT_2026-08-13.md` מתעד שארבעת דפי התמונה המלאים עדיין משתמשים בנכסי JPG דחוסים שאינם נכסי המקור הסופיים להדפסה. מקורות ה־PNG האיכותיים אומתו, אך יש להכניסם לריפו עצמו לפני שמכריזים שהפער הזה סגור. אין לעקוף זאת באמצעות קישור Drive פרטי או CSS בלבד.
