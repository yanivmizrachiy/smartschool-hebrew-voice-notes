# מעגל, גליל וחרוט — חוברות עבודה במתמטיקה

הריפו הזה מכיל שלוש חוברות נפרדות: **מעגל, גליל וחרוט**, יחד עם דפי A4, תשתיות הדפסה, QA וכלי build.

## מצב נוכחי

- **מעגל:** 88 דפי A4.
- **גליל:** 38 דפי A4.
- **חרוט:** 38 דפי עבודה + 8 דפים חזותיים = 46 דפי A4 בחוברת המלאה.
- דף 17 בחרוט נשאר source-locked.

## מקור האמת היחיד

**`RULES.md` הוא מקור האמת היחיד והמחייב של כל פרויקט מעגל–גליל–חרוט.**

`content/workbook.json`, `content/source-registry.json`, קובצי `research/`, `qa/` ושאר הקבצים הם נתוני יישום, מקורות, מחקר או תיעוד בלבד. הם אינם מקור דרישות ואינם רשאים לסתור או לגבור על `RULES.md`.

אין להסתמך על זיכרון שיחה במקום `RULES.md` שב־repo.

## פקודות איכות

- `npm run build` — מסנכרן את דפי ה־worksheet והדפים החזותיים של תשתית החרוט הנוכחית.
- `npm run build:print` — בונה את חבילת ההדפסה המאוחדת של החרוט.
- `npm run validate` — מפעיל את חוזי התוכן, המתמטיקה, המספור, המקורות, הדפים החזותיים והיגיינת הריפו הקיימים.
- `npm run check` — build + print + validate.
- `npm run render:pages` — מרנדר את רצף A4 דרך Chrome כאשר שרת מקומי פעיל ב־`127.0.0.1:4173`.

## CI

`Cone workbook quality` ו־`Textbook layout render` הם שערי האיכות הקיימים של חוברת החרוט. בדיקות נוספות של מעגל וגליל נשמרות לפי המימוש הקיים בריפו. שינוי בתשתית ייעשה רק אם יש צורך אמיתי וללא רגרסיה.

## מבנה הריפו

- `circle/` — דפי המעגל.
- `cylinder/` — דפי הגליל.
- `worksheets/` — דפי worksheet של החרוט.
- `visual-pages/` — דפי חוויה/תשובה של החרוט.
- `visual-assets/` — נכסים חזותיים מקומיים.
- `content/` — manifest ורישום מקורות של המימוש הקיים.
- `questions/` — מקורות, מפת שאלות ומפתח תשובות פנימי.
- `research/` — מחקר ופדגוגיה; אינו מקור דרישות.
- `viewer/` — אפליקציית הדפדוף וההדפסה.
- `src/` — מנועי build.
- `tests/` — חוזי איכות קבועים.
- `qa/` — ביקורות ותיעוד QA; אינו מקור דרישות.
- `print/harut-a4.html` — חבילת ההדפסה המאוחדת של החרוט לאחר build.

## היגיינת ריפו

קבצי staging, קובצי `*.b64`, workflows חד־פעמיים, קובצי `DO-NOT-MERGE`, סקריפטי `tools/apply-*` ופלט `qa/layout-pages/` אינם חלק ממקור האמת. `tests/repo-hygiene.mjs` מונע מהם לחזור ומוודא שאין תלות של תוצר התלמיד בקישורי Google Drive פרטיים.

## פער חזותי ידוע — חרוט

`qa/VISUAL_SOURCE_AUDIT_2026-08-13.md` מתעד שארבעת דפי התמונה המלאים עדיין משתמשים בנכסי JPG דחוסים שאינם נכסי המקור הסופיים להדפסה. מקורות ה־PNG האיכותיים אומתו, אך יש להכניסם לריפו עצמו לפני שמכריזים שהפער הזה סגור. אין לעקוף זאת באמצעות קישור Drive פרטי או CSS בלבד.
