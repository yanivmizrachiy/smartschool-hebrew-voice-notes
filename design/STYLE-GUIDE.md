# מדריך סגנון — חרוט לפי `razpages` ו״רביע ראשון״

מסמך יישום בלבד. מקור הכללים המחייב היחיד הוא `../RULES.md`.

## מקורות ייחוס
- `razpages/CLAUDE.md` — חוזי דפי עבודה, מספור, קרדיט, RTL ו־SVG.
- `razpages/styles/a4-base.css` — A4, header, footer והדפסה.
- `razpages/styles/topics/coordinate-first-quadrant.css` — צפיפות, כרטיסים, blanks, error-grid ושפת ״רביע ראשון״.
- `עמוד-531`, `עמוד-548`, `עמוד-555`, `עמוד-560` — דפי ייחוס חזותיים/פדגוגיים.

## דפי תלמיד
- דפי תרגול בלבד; אין דפי הסבר.
- אין מספור שאלות גלוי.
- מספר העמוד מופיע בכותרת.
- תתי־סעיפים א/ב/ג מותרים לפי צורך.
- אין תוויות כמו `תרגול`, `אתגר`, `העמקה`, `ביסוס`, `שלב N`.
- כותרת כרטיס מתארת תוכן, לא קושי.

## A4 והדפסה
- `210mm × 297mm`.
- בהדפסה: `@page { size: A4; margin: 0; }`.
- אין overflow, חפיפה או חיתוך.
- preview navigation מוסתר בהדפסה.
- צבעי הדפסה נשמרים עם `print-color-adjust: exact` כאשר נדרש.

## צפיפות — נקודת ייחוס מ״רביע ראשון״
- padding סביב `9mm 10mm 8mm` לפי התוכן.
- גוף טקסט סביב `12.4px`, line-height סביב `1.34`.
- כותרת עמוד סביב `23px`.
- כרטיס: border עדין, radius כ־`8px`, padding סביב `7px 9px`.
- כותרת כרטיס סביב `13.5px`, רקע עדין ו־border-bottom.
- מותרות מדרגות צפיפות שונות; אין לכווץ הכל באופן אחיד רק כדי להכניס לעמוד.

## מבנה כרטיס
- כותרת קצרה.
- הוראה קצרה ופועלית.
- גרפיקה/טבלה/בחירה רק אם היא משרתת את השאלה.
- `break-inside: avoid` בכרטיסים ובגרפיקות משמעותיות.
- שתי/שלוש עמודות רק כאשר זה משפר קריאות וניצול A4.

## מרחב תשובה
- מילה → blank קצר.
- מספר/ערך → תיבה או קו קצר.
- משפט → answer-line אחת.
- נימוק → 2–3 שורות לפי הצורך האמיתי.
- שרטוט → אזור שרטוט שימושי ביד.
- רוחבי blanks במחלקות `bw-*`; אין inline style.

## שאלות תיקון טעות
מבנה מועדף:
`מקרה → הכרעה → תיקון והסבר`.

- `error-grid` של שתי עמודות כאשר צפיפות מאפשרת.
- `mist-card` עם header עדין.
- אין להוסיף מלל הסבר שאינו חלק מהמשימה.

## SVG וגאומטריה
- תרשים מתמטי חדש נבנה SVG/HTML וקטורי, חד ובר־עריכה.
- stroke אחיד; `vector-effect="non-scaling-stroke"` כאשר מתאים.
- `role="img"` ו־`aria-label` לכל SVG משמעותי.
- מסיח חזותי מייצג טעות תלמיד סבירה, לא צורה אקראית.
- פריסה, חתך, מבט ותנוחה חייבים להיות מדויקים מתמטית.
- אין להפוך צילום מקור לתרשים מומצא אם נאמנות למקור דורשת raster.

## RTL ומתמטיקה
- הדף `dir="rtl"`.
- מתמטיקה/סימונים LTR עם `unicode-bidi:isolate` לפי הצורך.
- יש לבדוק סימני פיסוק, סוגריים, מספרים ויחידות בהדפסה.

## CSS
- CSS משותף + שכבת נושא/דף.
- אין inline CSS בדפים הסופיים.
- אין שכפול כללים בין שמונה דפים אם אפשר להגדיר class משותף.

## שאלה שמקורה בתוכנית הלימודים
כאשר היא נכנסת לדף, מוצגת כותרת מקור ברורה:
**מתוך תוכנית הלימודים**

הייחוס אינו מחליף את הקרדיט הקבוע בתחתית.
